# 🚗 Used Car Price Prediction

## 📌 Project Overview
I am currently working on a Used Car Price Prediction project to develop my practical skills in Data Science and Machine Learning. The goal is to build a machine learning model that predicts the price of a used car based on its features.

## 🎯 Objectives
- Explore and understand the dataset through Exploratory Data Analysis (EDA).
- Clean the dataset and handle missing values and duplicates.
- Perform feature engineering and extract useful information from engine specifications.
- Prepare numerical and categorical features for machine learning.
- Build and evaluate a model to predict used car prices.

## 📊 Work Completed So Far
- **Exploratory Data Analysis:** Analyzed data distributions and relationships between features.
- **Data Cleaning:** Handled missing values, duplicate records, inconsistent text, and data types.
- **Feature Engineering:** Extracted horsepower, engine size, and cylinder count from engine specifications.
- **Feature Creation:** Created a car-age feature using the model year.
- **Data Preprocessing:** Prepared numerical and categorical features using imputation, scaling, and one-hot encoding.
- **Model Exploration:** Experimented with Linear Regression and Random Forest Regression and evaluated their performance.
